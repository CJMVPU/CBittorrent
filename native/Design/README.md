# CB application icon

## Current artistic icon (0.3.1)

`Resources/CB-symbol.png` is the approved original artistic CB monogram with
its white background removed by the built-in imagegen tool. The calligraphic
shapes are shared by Dock, titlebar and menu bar through `App/BrandMark.swift`.
The geometric substitute shipped in 0.3.0 has been removed.

Final extraction prompt:

> Background removal only. Preserve the exact original artistic black interlocked
> italic serif CB monogram, shape, position and proportions. Remove all white
> background, including spaces inside C and B. Keep every serif and curve. Output
> only opaque black artwork with transparent surroundings, no redesign, new
> lettering, tile, border or shadow.

`scripts/render_brand.swift` packages the artwork on a clean white rounded tile
with transparent outer corners. `CB-app-icon.png` and `Resources/CBittorrent.icns`
are generated by `native/scripts/make_icon.sh`. The menu-bar template uses the
same artwork without the tile and receives its foreground color from macOS.

## Archived original artwork (0.2)

`CB-monogram.png` is the application artwork generated with the
built-in imagegen tool for this project. The user requested artistic CB letters,
black on white. No external logo or stock font artwork was used as a reference.

Final prompt (following an initial monogram generation):

> Preserve exactly the black CB lettering design, proportions and placement.
> Replace the whole background with pure solid opaque white edge to edge across
> the entire square canvas. Remove the rounded tile contour entirely: no tile
> boundary, no outline, no shadow, no transparency anywhere, no flecks or texture.
> Only the black CB monogram on one continuous perfectly white square background.
> Keep lettering comfortably inset. Output square app icon artwork.

The original generation specified bold sculpted calligraphic serif letterforms,
interlocked but legible C and B, and a balanced black-and-white composition.

The current ICNS still contains all standard sizes from 16pt through 512pt
at 1x and 2x scale, packaged with macOS `sips` and `iconutil`. The same
resource is referenced by Info.plist and the compact titlebar mark.
